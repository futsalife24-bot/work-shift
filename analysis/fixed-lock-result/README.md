架空Aは初週1休、その後2・2・3休で28日合計8休。ほか7人の架空補助員は `W8,W8,W8,MD,MD,OF,OF` を1日ずつずらした固定パターンとし、毎日W8が3人・MDが2人、全員が架空3区と海側・山側を担当可能。必要人数もこの構成に合わせる。日別不足・区不足・中勤翌日等の無関係な赤警告を消すための人工条件であり、実際の職場の必要人数・運用を提案していない。通常社員のみで、応援・休職例外による警告回避は使っていない。
